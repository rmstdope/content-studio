## The local gate failed on 5-second test timeouts with the load average near 150

**What happened.** `bun run check` took 869 s in the test step and ended with 20 failures and one
unhandled error, with `(fail)` lines timing out at bun's 5000 ms in files the diff does not touch.
The new tests, which spawn git, timed out the same way until they got a 60 s timeout. The same tree
passed under `bun test --timeout 60000` (6125 pass, 0 fail) once the load had fallen.

**Why.** `uptime` read load averages between 56 and 200 during the run. What caused the load was not
established.

**Cost.** One extra full run of the suite, about twenty minutes in all.

**Prevent by.** `package.json` `test` and `check`: pass `--timeout 30000`, so a busy machine does
not read as a regression.

**Seen before.** as-l7wb, as-bt1m.2.
